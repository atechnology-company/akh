## alif
Artificial Learning Integration for Fataawa

alif is an ai-powered search engine, using the [plates engine](https://github.com/atechnology-company/plates-mobile) 

using gemini 2.0 flash along with access to a wide base of pre-existing verified fataawa from a list of verifiable sources, you can input scenarios or complex queries for ai to dismantle, understand and provide relevant digestible rulings from verified sources
